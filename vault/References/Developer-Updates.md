# Funcom Developer Updates on Security

> From official Funcom developer update at duneawakening.com. 2026-09-19.

## Official Stance

> "We have zero tolerance for the type of player behaviour that has an impact on the experience of other players."

Funcom maintains a **dedicated team** exclusively focused on combating hackers and fixing exploits.

## Actions Taken

- **Several hundred players** banned for abusing exploits, cheats, and hacks
- Additional ban waves planned as more violators identified
- Players encouraged to report suspicious activity via in-game reporting

## Exploits Patched (Official List)

| Exploit | Description |
|---------|-------------|
| Account/Permission Spoofing | Bypassing base ownership/permissions |
| Building Dismantle Item Duplication | Duping items via dismantle mechanic |
| Increased Damage / Insta Kill | Client-side damage manipulation |
| Vehicle Inventory/VBT Item Duplication | Duping items through vehicle systems |
| Vehicle Ownership Takeover | Stealing vehicles via permission exploit |
| Projectile Weapon Rapid Fire | Rockets from ornithopters at abnormal rate |
| Durability Repair | Full durability restoration exploit |

## Planned Security Measures

Funcom stated they plan to:
1. **Increase security on client/server communication layer**
2. **Perform additional penetration testing** against common attack vectors
3. **Audit item and inventory systems** to prevent duplication exploits

## Logging Improvements

- Acknowledged lacking proper logging tools at launch
- Since improved systems to identify and reimburse vehicle losses
- Working on better forensics for exploit detection

## Key Patches

### Patch 1.1.10.0 (July 2, 2025)
- Fixed resource duplication exploit
- Fixed repair exploit (full durability restoration)
- Closed vulnerabilities leading to increased combat damage

### Patch 1.1.20 (August 12, 2025)
- "NPCs can no longer damage player-owned buildings or placeables in PvE areas"
- Fixed base-raiding-via-NPC exploit

### February 2026 Rollback
- Base exploit severe enough to roll back 5 servers
- Found issue allowing players to "unintentionally damage player bases in PVE areas"
- Made changes to prevent bypassing standard game mechanics
