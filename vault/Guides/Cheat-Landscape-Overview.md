## Common Feature Set

### ESP
- Player ESP: names, health, distance, skeleton
- NPC/AI ESP: enemy locations and types
- Loot ESP: item names, rarity, distance
- Resource ESP: spice blooms, rare materials
- Vehicle ESP: positions, types
- Trap ESP: placed traps through terrain

### Aimbot
- Bone selection (head, chest, limbs)
- Smoothing (human-like aim)
- FOV circle
- Prediction (projectile lead)

### Movement
- Speedhack, ghost mode (noclip), teleport, fly hack

### Combat
- Increased damage / insta-kill
- Rapid fire, no recoil / no spread

### Exploitation
- Item duplication, resource generation
- Repair exploit, permission spoofing
